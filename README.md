## Описание задачи

**Задача:** Регрессия (предсказание непрерывного значения)

**Что предсказываем:** Год выпуска песни (от 1922 до 2011)

**Датасет:** YearPredictionMSD (Million Song Dataset)
- **Источник:** UCI Machine Learning Repository
- **Ссылка:** https://www.kaggle.com/datasets/uciml/msd-audio-features
- **Объём:** 515,345 треков, 90 признаков

**Признаки:**
- 12 тембральных средних (TimbreAvg1-12)
- 78 ковариаций тембра (TimbreCovariance1-78)

**Целевая метрика:** MAE (Mean Absolute Error) — основная метрика, так как:
- Интерпретируема: "ошибка в среднем на X лет"
- Линейный штраф за ошибку

**Дополнительные метрики:** RMSE, R²

**ДЕЙСТВИЯ ПРИ РАСХОЖДЕНИИ МЕТРИК:**
- 1: MAE НИЗКАЯ, НО RMSE ВЫСОКАЯ
   Причина: наличие выбросов (модель сильно ошибается на отдельных объектах)
   Действие:
     1. Проверить наличие аномалий в предсказаниях
     2. Проанализировать объекты с наибольшими ошибками
     3. Возможно, требуется удалить выбросы из данных
     4. Или использовать робастные модели (Ridge, Lasso, Huber)

- 2: MAE НИЗКАЯ, НО R² НИЗКИЙ
   Причина: данные имеют высокую вариативность, не объясняемую моделью
   Действие:
     1. Добавить новые признаки (feature engineering)
     2. Использовать более сложные модели (Random Forest, XGBoost)
     3. Проверить, не предсказывает ли модель просто среднее значение

- 3: R² ВЫСОКИЙ, НО MAE ВЫСОКАЯ
   Причина: модель хорошо объясняет дисперсию, но систематически ошибается
   Действие:
     1. Проверить наличие смещения (bias) в предсказаниях
     2. Выполнить калибровку модели
     3. Добавить константу смещения в предсказания

- 4: МЕТРИКИ ПРОТИВОРЕЧАТ ДРУГ ДРУГУ ПРИ СРАВНЕНИИ МОДЕЛЕЙ
     1. Ориентируемся на MAE при выборе лучшей модели
     2. Если MAE близки (±0.3), смотрим на RMSE и R²
     3. Отдаём предпочтение модели с лучшим RMSE (меньше крупных ошибок)

- 5: ОБУЧАЮЩИЕ И ВАЛИДАЦИОННЫЕ МЕТРИКИ СИЛЬНО РАЗЛИЧАЮТСЯ
   Переобучение (overfitting)
   Действие:
     1. Уменьшить сложность модели (меньше деревьев, меньше глубину)
     2. Добавить регуляризацию
     3. Увеличить размер обучающей выборки
     4. Уменьшить количество признаков (feature selection)

### Сравнение baseline моделей

| Модель | Val MAE (лет) | Train MAE (лет) | Время обучения (сек) | Переобучение |
|--------|---------------|-----------------|---------------------|--------------|
| Linear Regression | 6.7005 | 6.6967 | 4.95 | 0.0039 |
| Ridge Regression | 6.7005 | 6.6966 | 0.62 | 0.0039 |
| Lasso Regression | 6.6951 | 6.6917 | 70.96 | 0.0033 |
| Decision Tree | 6.8565 | 6.5809 | 176.96 | 0.2756 |
| **Random Forest** | **6.5948** | 6.3612 | 42169.27 | 0.2336 |

### Анализ результатов

#### 1. Линейные модели (Linear, Ridge, Lasso)
- **MAE**: ~6.70 лет
- **Время обучения**: от 0.62 до 70.96 секунд
- **Переобучение**: отсутствует (разница train-val < 0.004)
- **Вывод**: линейные модели дают одинаковое качество, Ridge самый быстрый

#### 2. Дерево решений (Decision Tree)
- **MAE**: 6.8565 лет (хуже линейных на 0.16 лет)
- **Переобучение**: заметное (разница 0.2756 лет)
- **Вывод**: без ограничения глубины дерево переобучается

#### 3. Случайный лес (Random Forest)
- **MAE**: 6.5948 лет (лучший результат)
- **Улучшение относительно линейных**: -0.1057 лет (-1.6%)
- **Время обучения**: 42169 секунд (~11.7 часов)
- **Переобучение**: умеренное (разница 0.2336 лет)

### Ключевые выводы

1. **Лучшая baseline модель**: Random Forest (MAE = 6.5948 лет)

2. **Почему Random Forest лучше линейных моделей**:
   - Зависимость года от тембра не является строго линейной
   - Случайный лес распознает нелинейные паттерны в данных
   - Ансамбль деревьев устойчивее к шуму

3. **Компромисс качество vs скорость**:
   - Линейные модели: ~6.70 лет MAE, секунды обучения
   - Random Forest: ~6.59 лет MAE, часы обучения
   - Улучшение качества (+1.6%) не оправдывает затраты времени
